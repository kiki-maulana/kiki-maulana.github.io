Raw JSON Response



  
  
  

    The trip planner uses OpenTripPlanner engine.

    The OTP engine can be accessed at https://ptplanner.latrobe.edu.au
    


    To get the JSON result, you can send http request using the following format:
    

    https://ptplanner.latrobe.edu.au/otp/routers/{STATE_CODE}/plan?fromPlace={lat,lon}&toPlace={lat,lon}&date={YYYY-MM-DD}&time={HH24:MI}&mode=TRANSIT,WALK&numItineraries=1
    


    The following example retrieve the trip plan from Melbourne Central to La Trobe University (Agora), on 1 April 2025 at 08:00
    

    https://ptplanner.latrobe.edu.au/otp/routers/vic/plan?fromPlace=-37.8103528,144.9633012&toPlace=-37.7208129,145.0473987&date=2025-04-01&time=08:00&mode=TRANSIT,WALK&numItineraries=1
